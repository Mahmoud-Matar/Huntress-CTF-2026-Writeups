# Huntress CTF 2026 Writeups

Challenge reports currently present in this project. This local-file index is not a live Game Master status board. A report may cover multiple modes; a completion note means the report documents an accepted or completed result somewhere, not necessarily that every mode is complete. Where no completion result is documented, that is called out explicitly.

The writeup format is based on [RyanNgCT’s CTF Writeup Template](https://github.com/RyanNgCT/CTF-Writeup-Template), with attribution retained in applicable reports.

Project analysis helpers and answer builders are collected in the [`tools/` directory](tools). Reports that use a project script link directly to its file there. External utilities named in a report (for example, `readelf` or `tshark`) are system dependencies and are not bundled with these scripts.
